# MazeRace
🕹️ **MazeRace — 单机手电筒迷宫游戏**  
在黑暗中举着手电筒，用最快速度冲向右边的出口！  

- 🔦 **30°锥形真实光照** — 光线被墙壁精确遮挡，无穿墙漏光  
- 🧠 **迷雾记忆系统** — 走过的路、前方3格永久可见  
- 🌀 **传送阵** — 踩上传送阵选择目标，方向键/空格随机，Esc取消  
- 🪙 **金币收集** — 只出现在通往终点的路上，光照内外均可见  
- ⚙️ **难度滑块(1-100)** — 控制迷宫分支与曲折度，低难度更宽敞  
- 🖥️ **WinForms (.NET 4.8)** — 双缓冲高清绘制，高DPI适配，原生流畅体验  

🔗 纯单机，键盘操控，每次随机生成迷宫，考验你的空间记忆和路线规划！
